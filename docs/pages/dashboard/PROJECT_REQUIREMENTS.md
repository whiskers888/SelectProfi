## 🏆 ПРАВИЛА НАПИСАНИЯ КОДА (CODE QUALITY RULES)
1. **Чистота фронтенда (Критично!):** 
   - Никаких «божественных компонентов» на 500 строк. Разбивать на мелкие функциональные компоненты.
   - Строгая типизация TS. Никаких `any`. 
   - Вся стилизация — только через классы Tailwind. 
   - Никаких неиспользуемых импортов (no unused imports).
2. **Чистота бэкенда:** Разделение ответственности (Controllers -> Services -> Repositories). Никакой логики в контроллерах.
3. **Запрет заглушек:** Никаких `// TODO`, `// здесь логика` и `throw new NotImplementedException()`. Только рабочий production-ready код.
4. **Безопасность:** Валидация входных данных на бэке, обработка ошибок (try-catch, middleware), корректные HTTP-статусы.

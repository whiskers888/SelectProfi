# Инструкция для автономной ночной смены

Я ухожу спать. Ты работаешь в автономном режиме до утра. Твоя главная инструкция — файл `PROJECT_REQUIREMENTS.md`. 

Перед началом работы закоммить все текущие изменения, вытащи изменения из текущей ветки в свою новую ветку, создай её под себя (например, `feature/night-shift-refactor`).

Выполни следующие шаги без остановок и без запросов ко мне:

1. Прочитай `PROJECT_REQUIREMENTS.md` и `AGENTS.md`.
2. Используя MCP `yougile`, разбей все Эпики из ТЗ на конкретные задачи и создай их в колонке Backlog в «Технические задачи проекта» (там есть разделения для front/back/architecture). Сделай подробные описания задач (какие файлы менять, какие макеты смотреть в `docs/pages/dashboard`).
3. Начинай выполнять задачи по одной, строго по порядку (сначала Бэкенд и Аудит старого кода в `dashboard-app`, потом Фронтенд).
4. При выполнении каждой задачи: переведи её в In Progress, напиши код, проверь сборку через `dotnetdevmcp` (для бэка) или `npm run build` (для фронта). Если есть ошибки — исправляй их сам.
5. Когда задача готова: сделай `git commit`, переведи задачу в Review и добавь в YouGile комментарий с отчетом.
6. Веди дневник в файле `NIGHT_SHIFT_LOG.md`: записывай, что сделано, какие были ошибки и время.
7. Переходи к следующей задаче.

**УСЛОВИЯ ОСТАНОВКИ:**
Если ты чувствуешь, что контекст переполняется, упираешься в лимит запросов, или все задачи в Backlog закончились:
- Сохрани текущий файл, сделай коммит.
- Переведи задачу в In Progress с комментарием "Требуется продолжение" (если лимит) или в Done (если задачи кончились).
- Напиши в чат "ЖДУ СБРОСА ЛИМИТА" или "ВСЕ ЗАДАЧИ ВЫПОЛНЕНЫ".
- **После этого, чтобы сэкономить электроэнергию, выполни команду для перевода ПК в спящий режим: `rundll32.exe powrprof.dll,SetSuspendState 0,1,0`**

Начинай прямо сейчас. Увидимся утром.

# Что внутри выгрузки MagicPath

Это полноценный исходный проект на **React + TypeScript + Vite** (а не только HTML-снимок страницы). Источник интерфейса необычен: большая оригинальная HTML-строка в компоненте React, CSS-файл с переопределениями и модуль JS, который вручную перерисовывает DOM через `innerHTML`.

## Подтверждено статическим анализом
- `renderPoolV3` — кандидаты проекта.
- `renderAddCandidateV5` — отдельная страница добавления кандидата.
- `renderResponsesV4` / `openResponseFiltersV4` — отклики и модальные фильтры.
- `renderJobV4`, `downloadJobTxtV4`, `printJobPdfV4` — вакансия исполнителя и экспорт.
- `renderPaymentV3` — демонстрация комиссии и резервов.
- `openChatDrawer` — чат заказчика.

## Еще не присутствует в этой выгрузке
- `removeCandidateV6` и кнопка удаления кандидата из проекта.
- Общая функция корректного склонения числительных стажа. В карточках есть шаблоны `${p.years} лет`, `${a.experience} лет`, которые дают неверный русский для 2–4 лет.

`node --check src/components/generated/SelectProfiLegacy.js` прошёл успешно. Полная сборка Vite с зависимостями и ручной интерактивный тест не выполнялись.
